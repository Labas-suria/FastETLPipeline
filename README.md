# FastETLPipeline
Uma ferramenta para a criação de um pipeline ETL de dados de forma simples e rápida.

### Google API
Se a sua pipeline irá realizar a conexão com a API do Google Sheets é necessario que o arquivo de credenciais gerado para a autenticação seja salvo na raiz do projeto com o nome "credentials.json".

Caso queira mudar o caminho para o arquivo de credenciais, alterar o caminho da varíavel "credentials.json" no arquivo variables_paths.json.

[Guias de início rápido explicam como configurar e executar um app que chama uma a API Google Workspace.](https://developers.google.com/docs/api/quickstart/python?hl=pt-br)
